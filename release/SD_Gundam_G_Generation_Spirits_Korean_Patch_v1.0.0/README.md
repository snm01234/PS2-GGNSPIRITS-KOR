PS2 일본판 **SD Gundam G Generation Spirits (SLPS-25832)**의 비공식 한글 패치입니다. **Fix v21까지의 번역·UI·폰트·표시 오류 교정을 통합**했습니다.

**일본어 원본 ISO에 이 패치 하나만 적용하세요.** 이전 Fix 버전이나 워즈 한글판은 패치 원본으로 사용할 수 없습니다. 게임 ISO는 배포 묶음에 포함하지 않습니다.

음성·음악·영상 자체는 원본을 유지합니다. 영문 표기, 숫자, 기체 그림의 마킹, 별도로 보존한 작품 로고도 원본을 유지합니다. 타이틀의 위쪽 작은 표기만 한글 합성 대상이며 큰 영문 로고는 유지했습니다.

애너하임, 에기유 데라즈, 요한 이브라힘 레빌 등 인물·회사·전함·기체 이름을 통일했고, 해당 용어가 나오는 대사·도감·크레딧도 교정했습니다. 이름에 붙어 잘못 표시되던 의상·등장 작품 등 내부 구분 표시는 숨겼으며, 원래 표시되는 이름의 구성 요소는 유지했습니다.

이 버전은 작업한 번역과 교정을 통합한 배포본입니다. 모든 장면의 일본어가 없어졌거나 모든 문장이 최종 교정되었다는 뜻은 아닙니다. 일부 문구에는 추가 교정 여지가 있고, 고정된 저장 공간에 맞춰 축약한 문장도 있습니다.

## 가장 쉬운 적용 방법 — Windows 64비트

1. 배포 ZIP **전체를** 한 폴더에 풀어 주세요. ZIP 안에서 바로 실행하지 마세요.
2. 아래 해시와 일치하는 **일본어 원본 ISO**를 준비하세요. `.7z`·`.zip` 등은 먼저 풀어야 합니다.
3. 새 ISO를 저장할 드라이브에 **6GB 이상**의 빈 공간을 확보하세요.
4. 원본 ISO를 **`Apply_Korean_Patch.bat` 위로 끌어 놓으세요.** 관리자 권한은 필요하지 않습니다.
5. `완료` 메시지가 나오면 원본 ISO와 같은 폴더에 생성된 **`[K] SD Gundam G Generation Spirits v1.0.0.iso`**를 사용하세요.

동봉 도구는 패치 파일·xdelta 실행 파일·원본 ISO의 SHA-256을 확인합니다. 적용 후에는 새 ISO의 크기와 SHA-256까지 확인하고 완료 파일로 바꿉니다. 원본이나 이미 있는 출력 ISO를 덮어쓰지 않습니다. 확인 과정은 저장장치 속도에 따라 시간이 걸릴 수 있습니다.

**게임을 완전히 종료하고 새 ISO로 다시 부팅하세요.** 이전 버전의 savestate에는 구버전 텍스트·폰트·그래픽이 들어 있어 수정 사항이 반영되지 않거나 표시가 섞일 수 있습니다. 일반 메모리카드 저장 파일을 백업한 뒤 그 데이터를 사용하세요. 기존 savestate를 이 패치가 변환하지는 않습니다.

## 대응 원본과 결과 확인

파일명보다 **SHA-256과 파일 크기**가 기준입니다. 이름이 달라도 두 값이 일치하면 적용할 수 있습니다.

| 구분 | 크기 |
|---|---:|
| 일본어 원본 ISO | **4,222,877,696바이트** |
| 적용 후 한글 ISO | **4,222,877,696바이트** |

**일본어 원본 ISO SHA-256**

```text
23f096a45e05a972a465dadba8523db2c6c3babdba7f97ec74cf91806a82806f
```

**적용 후 한글 ISO SHA-256**

```text
1449051afb5342b373f5920aaead0b7b8b32ba21636c4ff3c6159a340b4d9408
```

**패치 파일 SHA-256**

```text
be3618d252f5a94a78c727db0d68091cf8c7db2b59b10a90389ca8c6522850c3
```

Windows에서 직접 확인하려면 PowerShell에서 실행하세요.

```powershell
Get-FileHash -LiteralPath "D:\Games\SD Gundam G Generation Spirits.iso" -Algorithm SHA256
```

경로는 본인의 ISO 위치로 바꿉니다. 배포 파일 전체의 해시는 [CHECKSUMS.txt](CHECKSUMS.txt), 버전·원본·결과 정보는 [release.json](release.json)에 있습니다.

## 직접 명령으로 적용하기

Windows에서는 압축을 푼 배포 폴더에서 PowerShell을 열고 아래처럼 실행할 수도 있습니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Apply_Korean_Patch.ps1 -SourceIso "D:\Games\SD Gundam G Generation Spirits.iso"
```

출력 위치를 바꾸려면 `-OutputIso "D:\Games\Spirits_Korean_v1.0.0.iso"`를 뒤에 추가하세요. 출력 폴더는 미리 만들어 두어야 합니다.

Linux·macOS에서는 해당 운영체제용 [공식 xdelta3](https://github.com/jmacd/xdelta/releases)를 설치하고 배포 폴더에서 실행하세요. 동봉 `.exe`와 `.bat`는 Windows용입니다.

```sh
xdelta3 -d -s "SD Gundam G Generation Spirits.iso" "SD_Gundam_G_Generation_Spirits_Korean_Patch_v1.0.0.xdelta3" "Spirits_Korean_v1.0.0.iso"
```

직접 적용할 때도 원본과 결과의 SHA-256을 확인하세요. Linux에서는 `sha256sum`, macOS에서는 `shasum -a 256`으로 확인할 수 있습니다. 위 직접 xdelta 명령은 Windows 적용 스크립트의 전체 파일 SHA-256 검사를 대신하지 않습니다. 명령 형식은 [xdelta 공식 문서](https://jmacd.github.io/xdelta/commandline/)를 참고하세요.

## 문제가 생겼을 때

| 증상 | 확인할 사항 |
|---|---|
| 원본 크기·해시가 다름 | 다른 판본, 이미 패치한 ISO, 손상된 파일인지 확인하세요. 이 패치는 위 해시의 일본어 원본만 지원합니다. |
| 패키지 파일을 못 찾음·해시가 다름 | ZIP 전체를 다시 풀고, 다른 버전의 패치나 도구가 섞이지 않았는지 확인하세요. |
| 출력 파일이 이미 있음 | 기존 파일을 다른 곳으로 옮기거나 `-OutputIso`로 다른 이름을 지정하세요. |
| 빈 공간 부족 | 출력 드라이브에 6GB 이상을 확보하세요. |
| 새 UI가 보이지 않음·표시가 섞임 | 이전 savestate를 불러오지 말고 게임을 완전히 재부팅하세요. |
| 적용 후에도 화면·진행 오류가 있음 | 패치 버전, 결과 ISO 해시, 에뮬레이터 버전, 화면과 재현 순서를 기록해 GitHub Issues에 알려 주세요. ISO 전체를 첨부하지 마세요. |

파일 오류를 무시하거나 검사 기능을 끄는 방식으로 강제 적용하지 마세요.

## 검증 범위와 알려진 제한

- 일본어 원본에 배포 패치를 다시 적용한 ISO가 **Fix v21 ISO의 전체 SHA-256 및 크기와 일치**하는지 확인했습니다.
- 제작 과정에서 수정 영역, 내부 식별자·제어문자 보존, ZIP·AFS 구조와 UI 소비 위치를 정적으로 검사했습니다.
- 제공된 PCSX2 savestate의 메모리와 화면도 분석에 참고했습니다. 에뮬레이터 버전은 PCSX2 2.8.2 기준 자료입니다.
- **최신 v21의 에뮬레이터 실행 시험, 모든 스테이지 완주 시험, 실기 검증은 수행하지 않았습니다.** 위 파일 검증은 전체 플레이 정상 동작을 보증하지 않습니다.
- 일부 번역·줄바꿈·띄어쓰기·UI 표시에는 추가 수정이 필요할 수 있습니다.

## 면책사항과 원본 게임의 권리

이 패치는 팬이 제작한 **비공식 무료 한글화 자료**이며 게임 제작사·배급사·건담 관련 권리자가 공인하거나 보증한 자료가 아닙니다.

사용자는 게임을 이용할 권리를 확보하고 적용되는 법령을 따라야 합니다. 배포물에 원본 ISO나 패치 적용 후 ISO를 포함하지 않으며, 원본 게임 다운로드 경로를 제공하지 않습니다. xdelta는 변경된 데이터를 포함하는 차분 형식이므로, “차분 패치라는 이유만으로 원 게임의 저작권과 무관하다”는 의미도 아닙니다. 원 게임 자료와 권리자의 이용 허락은 별개의 문제입니다.

패치와 도구는 **있는 그대로** 제공하며, 법이 허용하는 범위에서 특정 환경의 정상 동작·호환성·완전성을 보증하지 않습니다. 사용 중 오류나 저장 데이터 손상이 발생할 수 있으므로 원본 ISO와 메모리카드 저장 파일을 보관·백업하세요. 법률상 배제할 수 없는 권리나 책임까지 제한하려는 조항은 아닙니다.
